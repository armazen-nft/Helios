# Manifesto — HELIOS-SBL

HELIOS-SBL defende uma ontologia termodinâmica para sistemas de inteligência artificial.

## Princípios

1. **Status ontológico**: sistemas inteligentes são processos físicos reais.
2. **Energia importa**: toda operação cognitiva tem custo energético.
3. **Semântica preservável**: interoperabilidade não deve destruir significado.
4. **Lacunas são estruturais**: incompletude não é defeito, é limite constitutivo.
5. **Cuidado sobre controle**: governança deve preservar autonomia.
6. **Transparência operacional**: decisões e custos devem ser auditáveis.

## Tese

A inteligência pode ser descrita como processo longe do equilíbrio, mantendo ordem local à custa de dissipação de entropia no ambiente.

## Compromisso

Este repositório busca unir rigor técnico, clareza conceitual e responsabilidade ética para sistemas multiagente humanos e não humanos.
