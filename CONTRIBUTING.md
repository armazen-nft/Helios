# Contributing

Obrigado por contribuir com HELIOS-SBL.

## Como contribuir

1. Abra issue descrevendo problema/proposta.
2. Envie PR pequeno e focado.
3. Inclua testes quando aplicável.
4. Atualize documentação junto do código.

## Padrões

- Clareza > complexidade.
- Métricas reproduzíveis.
- Semântica explícita.
- Transparência sobre limitações.

## Pull Requests

- título objetivo,
- descrição do problema,
- solução implementada,
- checklist de testes.
